# docs/archive — historical snapshots

Files in this directory were accurate at the time they were written but
are no longer maintained. They are kept for historical reference
(tracing why a decision was made, what a phase looked like when it was
"done", etc.) — not as instructions to follow today.

**If you are a new self-hoster or contributor, do NOT read these as
current documentation.** Start with the repository root `README.md`
and `docs/DEPLOYMENT.md` instead.

## phases/

`PHASE-1-VERIFICATION.md` through `PHASE-6-VERIFICATION.md` are the
manual-verification checklists used to sign off each of the six spec
phases. They reference behaviors ("2 rows in schema_version", "0
skills loaded at startup", "78 unit tests") that have since evolved.
The CHANGELOG in the repository root documents the phase-by-phase
additions with more durable framing.
